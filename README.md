# QUBE – Vállalati hálózati infrastruktúra

A **QUBE** egy vállalati hálózati infrastruktúra tervezésére és prototípusban történő megvalósítására készült projekt.

A cél egy **biztonságos, redundáns, skálázható és magas rendelkezésre állású hálózat** kialakítása több telephely számára.

### Főbb technológiák

* VLAN alapú hálózati szegmentáció
* STP / Rapid PVST
* EtherChannel / LACP
* HSRP gateway redundancia
* DHCP Snooping, DAI és Port Security
* ACL és NAT/PAT
* GRE telephelyek közötti kapcsolatok
* Active Directory, DNS és DHCP
* Linux alapú hálózati szolgáltatások
* RADIUS és NTP
* Zabbix monitoring és automatizáció
* Cisco vezeték nélküli hálózat

### Infrastruktúra

A projekt három fő telephely hálózati környezetét modellezi:

**KÖZPONT · BOLT · TERMELÉS**

A prototípusban a hálózati infrastruktúra Cisco eszközökön, a szerveroldali szolgáltatások pedig virtualizált Windows és Linux szervereken kerültek kialakításra.

### Projekt célja

A projekt során a hálózattervezéstől és konfigurációtól kezdve a szerverinfrastruktúrán át egészen a **biztonsági megoldások, redundancia, monitoring és automatizáció** teszteléséig egy komplex vállalati hálózati környezet került megvalósításra.
